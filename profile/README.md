## Hi there 👋

Welcome to **Snag's** GitHub space.

### What is GitHub?

GitHub is an online home for files that change over time, mostly code. Think of it like a shared Google Drive with a perfect memory. It records every edit, who made it and why, so nothing is ever lost and we can always roll back. It also lets people suggest changes and have them reviewed before they go live.

### How we use it

🛠️ **Building software.** The tools, integrations and data pipelines that keep Snag running live here. Changes are proposed, reviewed and tested before they reach anything customers or colleagues rely on.

🤖 **Saving agent skills.** Skills are short written guides that teach AI how to do Snag-specific work, such as running a report or understanding our data. We keep them in [`agent-skills`](https://github.com/Snag-Tights/agent-skills) so they are version-controlled and reviewed like code, and everyone uses the same, up-to-date version.

### Getting involved

Got an idea for a new skill or an improvement to an existing one? Open a pull request or get in touch with the data team. You don't need to be a developer to contribute.
